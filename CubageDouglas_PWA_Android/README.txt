CUBAGE DOUGLAS - PWA ANDROID

Fichiers à placer à la racine du dépôt GitHub :
- index.html
- manifest.webmanifest
- service-worker.js
- dossier icons avec icon-192.png et icon-512.png

GitHub Pages : Settings > Pages > Deploy from a branch > main > /(root).
Sur Android : ouvrir l'adresse dans Chrome > menu trois points > Installer l'application.
Après une première ouverture en ligne, fermer puis rouvrir l'application en mode avion pour vérifier le fonctionnement hors connexion.

Important : les mesures sont conservées dans IndexedDB sur le téléphone. Exporter régulièrement le CSV.
