CUBAGE DOUGLAS V3 - LIVRAISON CONSOLIDÉE

Cette version remplace tous les anciens fichiers patch/fix.

Déploiement GitHub Pages :
1. Exporter profils.csv et tiges.csv depuis l'application actuelle.
2. Dans le dépôt, supprimer les anciens fichiers, puis conserver le dépôt lui-même.
3. Déposer le contenu de ce ZIP à la racine.
4. Vérifier Settings > Pages > main / root.
5. Ouvrir en ligne, actualiser deux fois, fermer et rouvrir.

La base IndexedDB reste cubage-douglas-v151. Les données locales de la même adresse devraient rester accessibles.

Arbre : numéro + D130, profil tous les mètres, saisie clavier/vocale, fin de tige avec Htot et diamètre terminal.
Grume : numéro + longueur + pas 1/2/4 m, profil direct, aucune fin de tige.
